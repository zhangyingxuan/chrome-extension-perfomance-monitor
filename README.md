# 网站性能监控 Chrome 扩展

一个零配置、一键启动的网站运行时性能监控工具，专为前端开发者设计。实时采集内存、缓存、CPU 三大指标，可视化展示并支持导出详单，主要用于定位线上页面泄漏、高 CPU、高内存消耗脚本与缓存冗余。

## ✨ 功能特性

- 🚀 **零配置启动** - 安装即可使用，无需复杂配置
- 📊 **实时监控** - 实时采集内存、CPU、缓存三大核心指标
- 📈 **可视化展示** - 使用 Chart.js 提供直观的图表展示
- 💾 **数据导出** - 支持 CSV 格式数据导出，便于深度分析
- 🔍 **问题定位** - 自动检测内存泄漏、高 CPU 消耗脚本、缓存冗余
- 🛡️ **安全可靠** - 使用 Chrome Extension Manifest V3，符合最新安全标准

## 🛠️ 技术栈

- **前端框架**: Vue 3 (选项式 API)
- **构建工具**: Vite (最新版本)
- **图表库**: Chart.js 3.9 (轻量版)
- **开发语言**: TypeScript
- **扩展标准**: Chrome Extension Manifest V3

## 📦 安装与使用

### 开发环境搭建

1. **克隆项目**

   ```bash
   git clone <repository-url>
   cd chrome-extension-perfomance-monitor
   ```

2. **安装依赖**

   ```bash
   npm install
   ```

3. **开发构建**

   ```bash
   npm run dev
   ```

4. **生产构建**
   ```bash
   npm run build
   ```

### 安装到 Chrome

1. 打开 Chrome 浏览器，进入 `chrome://extensions/`
2. 开启"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择项目根目录下的 `dist` 文件夹
5. 扩展安装完成，可在浏览器工具栏看到扩展图标

### 使用方法

1. **启动监控**

   - 点击浏览器工具栏中的扩展图标
   - 点击"开始监控"按钮
   - 扩展将开始实时采集性能数据

2. **查看数据**

   - **实时指标**: 查看当前内存、CPU、缓存使用情况
   - **趋势图表**: 观察各项指标的变化趋势
   - **详细数据**: 查看历史数据的详细记录

3. **导出数据**

   - 点击"导出数据"按钮
   - 数据将以 CSV 格式下载
   - 可用于进一步分析和报告

4. **清空数据**
   - 点击"清空数据"按钮
   - 清除当前标签页的所有监控数据

## 🔧 监控指标说明

### 内存使用 (Memory Usage)

- **监控内容**: JavaScript 堆内存使用情况
- **检测能力**: 内存泄漏、高内存消耗
- **数据来源**: `performance.memory` API
- **预警阈值**: 持续增长超过 1MB 可能表示内存泄漏

### CPU 使用率 (CPU Usage)

- **监控内容**: 页面脚本执行 CPU 占用
- **检测能力**: 高 CPU 消耗脚本、长任务
- **数据来源**: Performance API + 执行时间估算
- **预警阈值**: 单次执行超过 100ms 可能影响用户体验

### 缓存大小 (Cache Size)

- **监控内容**: localStorage、sessionStorage、IndexedDB 等缓存
- **检测能力**: 缓存冗余、过大缓存
- **数据来源**: 各存储 API 统计
- **预警阈值**: 缓存项超过 1 天未使用可能为冗余

## 🎯 问题定位指南

### 内存泄漏检测

- **症状**: 内存使用持续增长，页面变慢
- **定位方法**: 观察内存图表趋势，查看详细数据
- **解决方案**: 检查事件监听器、定时器、闭包引用

### 高 CPU 消耗脚本

- **症状**: 页面卡顿、响应缓慢
- **定位方法**: 查看 CPU 使用率峰值，分析执行时间
- **解决方案**: 优化循环、减少 DOM 操作、使用 Web Worker

### 缓存冗余问题

- **症状**: 存储空间占用过大，加载缓慢
- **定位方法**: 查看缓存大小和冗余缓存项数
- **解决方案**: 定期清理过期缓存，优化存储策略

## ⚠️ 注意事项

### 权限说明

- **activeTab**: 访问当前活动标签页
- **storage**: 本地存储性能数据
- **scripting**: 注入监控脚本
- **<all_urls>**: 在所有网站运行内容脚本

### 性能影响

- 监控过程对页面性能影响极小（<1%）
- 数据采集间隔可配置（默认 2 秒）
- 页面不可见时自动暂停监控

### 兼容性

- Chrome 88+ (支持 Manifest V3)
- 支持大部分现代网站
- 对 HTTPS 网站有更好的支持

## 🐛 故障排除

### 常见问题

**Q: 扩展无法加载数据**
A: 检查网站是否支持 Performance API，尝试刷新页面

**Q: 图表不显示**
A: 确认 Chart.js 是否正确加载，检查控制台错误信息

**Q: 数据导出失败**
A: 检查浏览器下载权限，确认有可导出的数据

### 调试方法

1. 打开 Chrome 开发者工具
2. 查看 Console 标签页的错误信息
3. 在 Extensions 页面检查扩展状态
4. 使用 Vue Devtools 调试 Vue 组件
